# Sample data

The Excel files are supplied project artifacts from the original prototype.

The two CSV files were generated specifically for the corrected ML workflow:

- `modeling_clients.csv` — synthetic lead-level records with a clean target defined from pre-outcome attributes;
- `contract_scores_oof.csv` — 5-fold out-of-fold Random Forest propensity scores.

The CSV benchmark avoids using `Стадия работы с клиентом` as a predictive input.
